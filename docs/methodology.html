關於與方法論

All-VC-Info 是一份開放、非官方的投資機構名錄,橫跨九大地區:台灣、美國、日本、歐洲、南韓、東南亞、以色列、印度、加拿大。涵蓋十二種機構類型 — 創投、加速器、育成中心、企業創投、天使網絡與 syndicate、政府計畫、創業工作室、Micro-VC、家族辦公室、成長期股權與股權群募。

怎麼做的

這份資料由數百個平行研究 agent 組裝而成。每個地區切成 24–31 個切片(依階段、產業、類型與地理),每個 agent 用即時網路搜尋研究一塊切片,產出結構化且附來源的資料。接著用一支確定性的 Python pipeline 去重、以 JSON Schema 驗證每筆、再合併 — 重複者保留最高信心值並聯集來源。

溯源與信心度

每個量化數字 — 基金規模、單筆金額、股權 %、錄取率、成立年 — 都綁定一個附原文 quote 的來源;查不到的數字寧可留白,不猜。每筆並標示信心度:高(官方/一手)、中(可靠二手)、低(單一弱來源或過時)。點開任一機構即可閱讀其來源。

免責

非官方整理,僅供參考。數字可能過時,引用前請依各筆來源自行查證。程式碼與資料在 GitHub: tingwei161803/all-vc-info →
